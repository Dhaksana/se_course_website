Question 1 (5 Marks)

Discuss the importance of the Design phase in the Software Engineering lifecycle. Why is it considered the "technical kernel"?

Model Answer: Design is the technical kernel because it is the phase where abstract requirements are mapped into a physical/technical solution (the "how"). It establishes the architecture, data structures, and detailed component algorithms required before coding begins. Without it, the software lacks structure, leading to fragile, unmaintainable code.

Question 2 (10 Marks)

A logistics company wants to track 10,000 trucks in real-time. Define the Architecture and Deployment design required to achieve this.

Model Answer:
Architecture: Client-Server architecture is appropriate, where the trucks run Client software broadcasting location, and a central Server aggregates data. For real-time updates, an Event-Driven or publish/subscribe pipeline could augment this.
Deployment: The deployment will map the mobile client tracking software to IoT nodes inside trucks, relying on cellular network links to connect to a load-balanced cluster of App Servers in the cloud, backed by a fast NoSQL or specialized spatial database for high-throughput writes.
